## 🧊 Optional 3D Contribution Graph

A true 3D contribution graph requires a separate GitHub Actions workflow. A README image tag alone cannot generate the graph.

To configure one, follow the instructions in [github-profile-3d-contrib](https://github.com/ashutosh00710/github-profile-3d-contrib).

After the workflow generates the SVG in your repository, you can embed the generated image like this:

```html
<img src="./profile-3d-contrib/profile-night-rainbow.svg" alt="3D GitHub contribution graph"/>
```
